# Alerta Verde

**Diogo Paes Maia e João Paulo de Castro Portela**

Sistemas de Informação · 4º período · CESMAC · 2026.2

Desenvolvemos o Alerta Verde para o projeto integrado de Programação Orientada a Objetos, Engenharia de Software e Banco de Dados. Pelo site, quem encontra um problema em uma praça ou parque pode fazer uma denúncia identificada ou anônima e acompanhar a resposta do guarda com um protocolo e um código de acesso.

## Material da entrega

- **Aplicação** — [Código-fonte em Python e Flask](alerta/) com persistência em PostgreSQL.
- **Documentação** — [Requisitos do sistema (PRD)](prd.md), [arquitetura e pilares de POO](docs/arquitetura.md) e [especificações das funcionalidades](specs/).
- **Banco de Dados** — [Scripts SQL](sql/) e [PDF para avaliação](entrega/BD_Alerta_Verde.pdf) com as tabelas, a trigger, o índice, as contas e permissões e a view.
